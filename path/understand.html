The route

Island by island

17 islands, in the order to sail them.

Shared foundation

Step 01 · Island 01

AI literacy

What AI, machine learning and large language models are, what they can and can't do yet, and the words you'll see everywhere: model, training, parameters, tokens, prompts.

 15–30 h Step 02 · Island 02

Python

Variables, loops, functions, files and packages, then NumPy and pandas basics in a Jupyter or Google Colab notebook. Enough to read someone else's code and change it.

 40–80 h Step 03 · Island 03

Terminal, Git and GitHub

The terminal (moving around folders and running programs), Git for saving versions of your work, and GitHub for backing it up and sharing it. Most courses after this island hand out their material as GitHub repositories.

 10–20 h Step 04 · Island 04

Math for machine learning

Vectors and matrices, derivatives and gradients, probability and statistics. Every model you'll train rests on these three.

 60–100 h Step 05 · Island 05

Machine learning basics

Supervised and unsupervised learning, train, validation and test splits, overfitting, and the classic models (linear and logistic regression, decision trees, gradient boosting) in scikit-learn.

 70–110 h Step 06 · Island 06

Deep learning

Neural networks, backpropagation, convolutional nets and transformers at a working level, all in PyTorch, and what actually happens on a GPU during training.

 60–100 h

Understand first

Step 07 · Island 16

Neural nets from scratch

Write backpropagation yourself, then a character-level language model, until you understand every line a framework normally hides.

 30–50 h Step 08 · Island 17

A GPT from scratch

Attention, transformer blocks, the training loop and sampling. Write a GPT in PyTorch and load real GPT-2 weights into it.

 40–70 h Step 09 · Island 07

LLM APIs and prompting

How an LLM produces text, then how to call one from code: system prompts, examples in the prompt, structured JSON output, and tokens and what they cost.

 20–35 h Step 10 · Island 08

RAG: answers from your documents

Embeddings, vector search, chunking and retrieval-augmented generation, so a model answers from your own documents and cites them.

 30–50 h Step 11 · Island 09

Agents and tools

Tool use (function calling), agent loops, the Model Context Protocol (MCP), memory, and how to tell when a fixed workflow will do the job better than an agent.

 25–40 h Step 12 · Island 10

Evals and shipping

Test sets built from real examples, error analysis, LLM judges you've checked against people, then cost, latency, guardrails and monitoring once the app is live.

 25–40 h Step 13 · Island 11

Security and privacy

Prompt injection and why it can't be fully filtered out, limiting what tools and data an agent can reach, keeping API keys on the server, and what happens to the data you send to a model provider.

 15–25 h Step 14 · Island 12

Open models and Hugging Face

How transformers and tokenizers work inside, the Hugging Face libraries (Transformers, Datasets, the Hub), and running open-weight models on your own machine.

 30–45 h Step 15 · Island 13

Fine-tuning with LoRA

When fine-tuning beats prompting or RAG, how to build a training set, and supervised fine-tuning with LoRA and QLoRA on a single GPU.

 30–50 h Step 16 · Island 14

Preference tuning: RLHF, DPO and GRPO

How chat models learn to behave: instruction tuning, reward models, RLHF, DPO, and reinforcement learning with verifiable rewards (GRPO) for reasoning.

 30–50 h Step 17 · Island 15

Evaluate, quantize and serve

Public benchmarks versus your own task evals, quantization, and serving a model with tools such as vLLM, llama.cpp or Ollama, plus what each choice costs in speed and money.

 25–40 h

Learn by doing · the path project

Your own study assistant, built from the ground up

Pick a subject you care about and a folder of notes or PDFs on it. Island by island, you turn it into an assistant that answers questions about that subject, and by the end every part of it, from the math to the model it runs on, is something you have built or trained yourself.

  1. 01
    Island 01 · AI literacy

    Choose your subject and collect 20 real questions you would want answered. Ask three AI tools each question and write down where each one is wrong. These 20 questions become your first test set.

    CourseElements of AI ↗BookCo-Intelligence: Living and Working with AI ↗
  2. 02
    Island 02 · Python

    Write a Python script that loads your documents and your questions from a CSV file and prints a short summary: how many files, pages, words and questions.

    CourseCS50's Introduction to Programming with Python (CS50P) ↗GuideNumPy: the absolute basics for beginners ↗
  3. 03
    Island 03 · Terminal, Git and GitHub

    Put the project on GitHub. From here on, commit every step of this project in small, clearly named commits.

    CourseThe Unix Shell ↗CourseVersion Control with Git ↗
  4. 04
    Island 04 · Math for machine learning

    Turn each paragraph and each question into a vector of word counts and write cosine similarity yourself in NumPy, to find the paragraph that best matches each question.

    CourseLinear algebra ↗CourseCalculus 1 ↗
  5. 05
    Island 05 · Machine learning basics

    Label your questions by topic and train two scikit-learn classifiers to predict the topic. Compare them on questions they have not seen.

    CourseMachine Learning Specialization ↗BookAn Introduction to Statistical Learning with Python ↗
  6. 06
    Island 06 · Deep learning

    Train a small PyTorch network on the same topic task and compare it with the two classic models.

    CoursePractical Deep Learning for Coders ↗BookUnderstanding Deep Learning ↗
  7. 07
    Island 16 · Neural nets from scratch

    Write backpropagation for that network yourself, in the style of micrograd, and check that your gradients match PyTorch's.

    CourseNeural Networks: Zero to Hero ↗BookDive into Deep Learning ↗
  8. 08
    Island 17 · A GPT from scratch

    Train a tiny GPT on your documents and generate a few paragraphs in their style.

    VideoLet's build GPT: from scratch, in code, spelled out ↗BookBuild a Large Language Model (From Scratch) ↗
  9. 09
    Island 07 · LLM APIs and prompting

    Answer your questions through an LLM API, with a system prompt that says how to answer and when to admit it doesn't know.

    VideoDeep Dive into LLMs like ChatGPT ↗CourseBuilding with the Claude API ↗
  10. 10
    Island 08 · RAG: answers from your documents

    Add retrieval over your documents, so every answer quotes its source and shows the page it came from.

    CourseLLM Zoomcamp ↗BookHands-On Large Language Models ↗
  11. 11
    Island 09 · Agents and tools

    Give the assistant two tools: a web search for when your documents don't have the answer, and a way to save good answers to a notes file.

    CourseAgentic AI ↗BookAI Engineering (chapter 6, RAG and Agents) ↗
  12. 12
    Island 10 · Evals and shipping

    Grow your test set to 50 questions, score every answer, fix the worst failure, and put the assistant online as a small web app.

    CourseEvaluating and Improving Agentic Applications ↗BookAI Engineering (chapters 3 and 4, evaluation) ↗
  13. 13
    Island 11 · Security and privacy

    Attack your own assistant: write ten prompts that try to break its rules, hide an instruction inside one of your documents, fix what gets through, and keep every API key on the server.

    GuideOWASP 2025 Top 10 for LLMs and Gen AI Apps ↗GuideLLM Prompt Injection Prevention Cheat Sheet ↗
  14. 14
    Island 12 · Open models and Hugging Face

    Run an open-weight model on your own machine and compare it with the API model on your 50 test questions.

    CourseLLM Course (chapters 1 to 4) ↗BookHands-On Large Language Models ↗
  15. 15
    Island 13 · Fine-tuning with LoRA

    Fine-tune that open model with LoRA on about 1,000 question-and-answer pairs from your documents, and show that it beats the base model on your tests.

    CourseLLM Course, chapter 11: Fine-tune LLMs ↗BookLLM Engineer's Handbook ↗
  16. 16
    Island 14 · Preference tuning: RLHF, DPO and GRPO

    Use DPO to fix one behavior, for example always citing a page, then rerun your tests to check that nothing else broke.

    CoursePost-training of LLMs ↗BookReinforcement Learning from Human Feedback ↗
  17. 17
    Island 15 · Evaluate, quantize and serve

    Quantize your fine-tuned model, serve it behind your own API, point the web app at it, and run the full test set one last time.

    GuideThe LLM Evaluation Guidebook ↗BookAI Engineering (chapter 9, Inference Optimization) ↗
When you finish

A deployed assistant for your subject: retrieval with page citations, a fine-tuned open model served by you, a test set that proves it works, and a GitHub repository that tells the story step by step.

What you'll be able to build

Overview

A small GPT you wrote yourself, a fine-tuned open model that beats its base model on your own tests, and AI features in your apps that you can debug because you know what happens inside the model.

Good fit if you want to use, train and build models and understand every step, and you can study steadily for a year or more part-time.

Why take it

  • When a model fails, you can work out why and fix it instead of guessing.
  • Covers using, training and building, and leaves out only the research-scale islands.
  • The foundations (math, ML and PyTorch) stay useful as tools change.

What it costs you

  • Your first AI app comes after the foundations and the from-scratch islands, so expect months of groundwork before it.
  • Months of math and code before anything feels like AI, so it takes steady motivation.
  • It stops before pretraining at scale. Add the last two Build islands later if you aim for research.

Effort

What it will take

Math 3/5

Linear algebra, calculus and probability.

Code 4/5

PyTorch, training scripts and app code you write yourself.

GPU 3/5

Colab's free tier to start; rent a GPU for bigger fine-tuning runs.

Money 2/5

Mostly free; some GPU time and a few dollars of API credits.
